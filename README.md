# AI Text Summarizer using T5

This project is an AI-powered text summarization web application built using:

- Python
- FastAPI
- Hugging Face Transformers
- T5 Transformer Model
- PyTorch

The model is fine-tuned for text summarization tasks and can generate short summaries from long text conversations or paragraphs.

## Features

- AI-based text summarization
- FastAPI backend
- Simple web interface
- T5 transformer integration
- Custom fine-tuned model

## Tech Stack

- Python
- FastAPI
- Transformers
- PyTorch
- HTML
